# Shelve It

A Cities: Skylines II mod that organizes your installed assets into thematic libraries. Version 0.1.0 (beta).

If you run hundreds of asset packages, finding a coherent set of buildings for one neighbourhood means searching asset by asset. Shelve It scans what you have, proposes libraries on its own ("UK, residential medium", "Historic industry", a creator's pack) and makes them usable while you build.

## Features

- Asset scan: every placeable asset (buildings, props, decals) from the base game and from Paradox Mods packages.
- Suggested libraries, built from asset metadata and grouped in three trees: regions and styles, creator packs, themed sets. Accept a suggestion at any level with one click.
- Libraries work like tags, so an asset can sit in several of them.
- Find It bridge: type `lib:<library>` in Find It's search to show only that library. The panel also has an "Open in Find It" button.
- Filters in the style of Find It (type, zone, density, region, theme, asset pack, origin, package, level, lot size), search, sorting, and bulk add or remove on the filtered result.
- Palette mode: a compact view that stays open while you build. Click an asset to place it.
- Community sharing: publish a library, browse and import libraries from other players, or exchange share codes (`SHELVE1:...`) by chat. Packages you are missing can be subscribed in one step.
- English and Italian.

## Requirements

- Cities: Skylines II 1.6.x
- [Find It](https://mods.paradoxplaza.com/mods/77240/Windows) (required dependency)

## Install

Subscribe to [Shelve It on Paradox Mods](https://mods.paradoxplaza.com/mods/163296/Windows), in game or on the website. Find It is installed with it as a dependency. The toolbar button opens the panel.

## Privacy

The mod works offline. The community server (`https://shelveit.servermartino.com` by default, changeable in the mod settings) is contacted only on demand: when you open the Community tab, import a library, or publish one. What it receives:

- the library you publish: name, description, tags, mod version, and the assets and packages it contains;
- your Paradox display name, only when you publish or update a library, so other players see the author;
- a random install id generated by the mod, sent with publish, update and report requests.

Share codes do not touch the server at all. Full policy: https://shelveit.servermartino.com/privacy

## Build from source

Prerequisites:

- .NET SDK (6 or later; the project targets .NET Framework 4.8 like the game)
- Node.js 18 or later
- Cities: Skylines II installed (the build references the game's assemblies)

The game folder defaults to the standard Steam path. For any other install, set `CS2_INSTALL` as an environment variable or pass it to MSBuild:

```
set CS2_INSTALL=D:\Games\Cities Skylines II
dotnet build -c Release -p:CS2_INSTALL="D:\Games\Cities Skylines II"
```

`ManagedPath` (the game's `Cities2_Data\Managed` folder) and `DeployDir` (default `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\ShelveIt`) can be overridden the same way.

Steps:

```
cd ShelveIt/UI
npm install
npm run build
cd ..
dotnet build -c Release
```

The C# build copies the DLL, the `Data` files and the UI bundle into the local Mods folder. Close the game first, or the copy fails on a locked DLL.

When the official modding toolchain is installed (in game: Options > Modding), the project picks it up through the `CSII_TOOLPATH` variable and builds the same way the template does. Publishing is described in [PUBLISHING.md](PUBLISHING.md).

### Browser preview

`ShelveIt/UI/preview` renders the panel in a browser with mocked game modules, using the stylesheet and icons of the installed game:

```
cd ShelveIt/UI
node preview/tools/extract-classes.js "<game>/Cities2_Data/Content/Game/UI" preview/data/classes.json
node preview/tools/make-sample-fixtures.js
npx webpack --config preview/webpack.preview.js
node preview/serve.js
```

Then open http://localhost:5517/. The sample fixtures are synthetic. `make-fixtures.js` builds fixtures from your own scan instead; `preview/data` is git-ignored, keep it that way.

```
  Systems/                  ECS systems: asset scan, panel bindings, community tab
  Logic/                    suggestion engine, theme classifier, filters, Find It bridge, community client, share codes
  Domain/                   data models
  Data/themes.json          theme definitions used by the classifier

  UI/src/                   React and TypeScript panel
  UI/preview/               browser preview harness
```

## Contributing

Bug reports and pull requests are welcome. The easiest way to help is improving the data files, which need no C#:

- `ShelveIt/Data/themes.json`: each theme has an id, names in every language, the asset kinds and zones it applies to, and weighted keywords. Add a theme or tune keywords so that suggestions catch more of the right assets and fewer of the wrong ones.
- `ShelveIt/Data/community.json`: keywords for specific Paradox Mods packages, keyed by package id (for example `"92859": ["british"]`), for packages whose asset names do not say what they are.

Please keep both files valid JSON and test the result in game (the suggestion tree updates after a rescan). For code changes, follow the existing style and keep the panel cheap when it is closed.

## Italiano

Shelve It è una mod per Cities: Skylines II che scansiona gli asset installati e li organizza in librerie tematiche. Propone da sola librerie per regione e stile, per pack del creator e per set tematici; si accettano con un clic. In Find It basta cercare `lib:<libreria>` per vedere solo quella libreria (Find It è obbligatorio). Ci sono filtri in stile Find It, una modalità tavolozza da tenere aperta mentre si costruisce e la condivisione con la community, anche tramite codici da incollare in chat.

Il server community viene contattato solo su richiesta. Riceve il nome visualizzato Paradox solo quando pubblichi una libreria, più un id di installazione casuale. Dettagli: https://shelveit.servermartino.com/privacy

Per contribuire, il modo più semplice è migliorare `ShelveIt/Data/themes.json` e `ShelveIt/Data/community.json`.
