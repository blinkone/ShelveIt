# Changelog

## 0.1.0 (beta)

First public release.

- Scan of all placeable assets (buildings, props, decals) from the base game and Paradox Mods packages.
- Suggested thematic libraries in three trees: regions and styles, creator packs, themed sets. Suggestions can be accepted at any level.
- Libraries as tags: an asset can belong to several libraries.
- Find It bridge: `lib:<library>` search inside Find It, and an "Open in Find It" button.
- Filters (type, zone, density, region, theme, asset pack, origin, package, level, lot size), search, sorting and bulk actions on the filtered result.
- Manager view and compact palette mode for building.
- Community sharing: publish, browse and import libraries, share codes, one-step subscription to missing packages.
- Asset packages subscribed from Shelve It load during the session once downloaded, with per-package progress (downloading, loading, loaded, needs a restart).
- Main-menu button "Load new asset packages (N)" for downloaded packages that are not loaded yet. Packages that still fail to load get a quit-or-later prompt.
- The asset list is rescanned the next time the panel opens after new packages load. Find It keeps its own index and may need a restart to list them.
- English and Italian.
